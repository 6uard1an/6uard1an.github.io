Protected distribution

Paid books are not hosted on this website.

This public site contains no book packages, decryption keys, purchase tokens, reviewer credentials, or private account data. Book access is provided inside the signed Android app and checked against the signed-in account and server-verified Google Play ownership. Public web code can always be inspected, so protected content is deliberately kept out of the website rather than relying on obfuscation.
